# Сайт 3DETAILS

В архиве находятся главная страница и страница «Контакты».

Для публикации на GitHub Pages загрузите в корень репозитория все файлы и папку `assets`:

- `index.html`
- `style.css`
- `contacts.html`
- `contacts.css`
- папку `assets`
- `CNAME`
- `.nojekyll`

После загрузки GitHub Pages автоматически опубликует обновление.

## Как добавить ссылки

Откройте `contacts.html` и найдите комментарии `Замените # на ссылку`.
В нужной строке замените только символ `#` внутри `href="#"` на полный адрес страницы.

Пример:

```html
href="https://t.me/имя_профиля"
```

После добавления настоящей ссылки удалите у этой карточки класс `is-placeholder`, чтобы она стала кликабельной.
