# Сайт 3DETAILS

В архиве находятся главная страница, готовый раздел «3D-печать» и страница «Контакты».

Для публикации на GitHub Pages загрузите в корень репозитория все файлы и папку `assets`:

- `index.html`
- `style.css`
- `typography.css`
- `printing.html`
- `printing.css`
- `printing.js`
- `contacts.html`
- `contacts.css`
- папку `assets`
- `CNAME`
- `.nojekyll`

После загрузки GitHub Pages автоматически опубликует обновление.

## Единые шрифты — 17 ноября 2026

На всех трёх страницах заголовки используют **Oswald Bold (700)**, как заголовок «Воплощаем детали в материале» на главной. Текстовые абзацы используют **Roboto Condensed Medium (500)**, как вступительный абзац на странице печати. Размеры текста сохранены по назначению блоков.

Общие настройки вынесены в `typography.css`, который подключён после стилей каждой страницы. Шрифты находятся в `assets/fonts/` и работают без Google Fonts. На странице печати убрано горизонтальное сжатие заголовков, их размеры адаптированы к ширине блоков.

Проверено в браузере при ширине 1363, 768 и 375 px. Для публикации загрузите содержимое папки `3details_site-main` с заменой файлов, включая новый `typography.css` и всю папку `assets/fonts`. Сам ZIP в репозиторий загружать не нужно. Этот архив подготовлен для публикации; действующий сайт автоматически не обновлялся.

## Как добавить ссылки

Откройте `contacts.html` и найдите комментарии `Замените # на ссылку`.
В нужной строке замените только символ `#` внутри `href="#"` на полный адрес страницы.

Пример:

```html
href="https://t.me/имя_профиля"
```

После добавления настоящей ссылки удалите у этой карточки класс `is-placeholder`, чтобы она стала кликабельной.
